# Portfolio

A personal developer portfolio built with Next.js, React, TypeScript, and Tailwind CSS.

## Requirements

- Node.js 18 or later
- Yarn 4.18.1 (Corepack is recommended)

## Getting started

```bash
corepack yarn install
corepack yarn dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site.

## Scripts

| Command | Description |
| --- | --- |
| `corepack yarn dev` | Start the local development server |
| `corepack yarn lint` | Run ESLint |
| `corepack yarn build` | Create a production build |
| `corepack yarn start` | Serve the production build |

## Project structure

- `src/app` — App Router layout, page, and global styles
- `src/components` — Portfolio sections and reusable UI
- `src/data` — Portfolio content
- `public` — Static images, icons, and documents
